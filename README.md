# LuigiNES

A single-file NES emulator written in Python, styled after the Windows 98
shareware emulators of 1999. An homage to Gary Boyes' MarioNES 1.5 — same
interface philosophy, no shared code.

 
## Requirements

Python 3.14 or newer. No third-party packages, no build step, no installer.
Tkinter ships with CPython.
